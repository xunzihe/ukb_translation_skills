# SCI 中译英技能体系（NeuroReport × UKB）

将中文 SCI 学术论文翻译为符合国际期刊发表标准的英文，面向 **UK Biobank 队列研究**方向：加速度计身体活动、dMRI 结构连接、抑郁症流行病学。

## 技能组成

| 技能 | 职责 | 关键文件 |
|---|---|---|
| `sci-zh2en-translation` | 中译英执行：术语定译、句式控制、数值与语义保真 | `SKILL.md` + `references/`（术语表、期刊格式、翻译细则、质量测评） |
| `neuroreport-ukb-writing` | 按 NeuroReport 作者指南撰写/润色 UKB 论文 | `SKILL.md` + `references/ukb-lexicon.md` |

## 翻译工作流程（8 节点闭环）

```
① 通读定职责 → ② 提取锚点（数值/术语/缩写/语义）→ ③ 术语定译（查表/检索，不杜撰）
→ ④ 逐段翻译（保段落结构）→ ⑤ 句式控制（短句，长难句率≤10%）
→ ⑥ 指标测评（锚点回查→指标计算→测评报告）→ ⑦ 修复复测（循环到全过）→ ⑧ 交付（译文+报告）
```

## 术语参考来源

- **期刊层**：NeuroReport 官方作者指南（摘要 ≤250 词四段式、参考文献 ≤25 条、正文 ≤19,500 字符等）
- **术语层**：UKB 已发表论文真实用法（Doherty 2017 PLOS ONE、Pearce 2022 JAMA Psychiatry、Di 2026 Neurosci Bull 等），词表未覆盖的检索核实后采用，不杜撰

## 硬性保真约束

1. 数值零改动（样本量、统计量、阈值、时长、扫描参数一律原样保留）
2. 事实零改动（结论方向、因果措辞强度、比较关系、组别归属不变）
3. 不增补内容（原文没有的机制、文献、数据一律不加入）
4. 不擅改原文疑似笔误（单列"翻译说明"请作者确认）
